# استديو الشخصيات — بدون قيود

موقع ذاتي الاستضافة (self-hosted) لإنشاء شخصيات أنمي أو حقيقية، والتحدث معها (شات)، وتوليد صور وفيديوهات لها. أنت من يوصّل المحركات (LLM/صور/فيديو) — الموقع لا يحتوي مزوّد مدمج ولا رقابة محتوى من جهته، القيود الوحيدة هي ما يفرضه المحرّك الذي تربطه.

## التشغيل

```bash
npm install
cp .env.example .env
# عدّل .env: ضع روابط ومفاتيح محركاتك (LLM / صور / فيديو)
npm start
```

افتح `http://localhost:3000`.

## التركيبة

- **السيرفر**: Node + Express + SQLite (`better-sqlite3`), بدون أي بناء/تجميع.
- **الشات**: أي نقطة نهاية متوافقة مع `POST /chat/completions` بصيغة OpenAI (خادم محلي مثل llama.cpp/vLLM، أو أي مزود تدفع له). يُبنى system prompt من بيانات الشخصية (الاسم، المظهر، الشخصية، السياق) + تعليمة البقاء في الدور بدون كسر الشخصية.
- **الصور**: وضعان عبر `IMAGE_API_MODE`:
  - `sdwebui` → `POST {base}/sdapi/v1/txt2img` (متوافق مع A1111/ComfyUI shim).
  - `openai` → `POST {base}/images/generations`.
- **الفيديو**: نمط job-polling عام — `POST {base}/generate` يرجع `job_id`، والواجهة تستطلع `GET {base}/status/:id` كل 3 ثواني حتى `status: done` ثم يُنزَّل الملف محلياً.

## البنية

```
server/
  index.js          نقطة الدخول + الروابط الثابتة
  db.js             سكيمة SQLite (characters, messages, media)
  config.js         قراءة .env
  engines/
    llm.js          عميل الشات
    image.js        عميل الصور
    video.js        عميل الفيديو
  routes/
    characters.js   CRUD شخصيات
    chat.js         رسائل + استدعاء LLM
    media.js        توليد صور/فيديو + استطلاع حالة الفيديو
public/             الواجهة (SPA عادي، بدون فريمورك) — RTL عربي
data/
  app.db            قاعدة البيانات (تُنشأ تلقائياً)
  media/            الصور/الفيديوهات المولّدة
```

## ملاحظات مهمة

- **لا محرك مدمج**: الموقع هيكل/واجهة فقط. لتوليد فعلي تحتاج تشغّل أو تدفع لخدمة شات (OpenAI-compatible) وخدمة صور (SD WebUI/ComfyUI أو OpenAI-compatible) وخدمة فيديو بصيغة job-polling، وتضع رابط ومفتاح كل واحدة في `.env`. اختر خدمات بلا قيود محتوى بنفسك — هذا قرارك وعلى مسؤوليتك.
- `unrestricted` في جدول `characters` يتحكم بإضافة تعليمة "تبقى في الشخصية بدون رفض/تحذيرات" إلى system prompt الشات لتلك الشخصية بعينها.
- لا مصادقة/تسجيل دخول مبني — إضافته لازمة قبل النشر على الإنترنت العام. حالياً هذا مناسب للتشغيل المحلي أو خلف شبكة خاصة.
